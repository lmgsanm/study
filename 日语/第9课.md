# 语法

## 一、N は　A1 　です

> 一类形容词：A1；二类形容词：A2
>
> 一类形容词以「い」结尾
>
> 敬体时在后面加「です」

## 二、A1做谓语时的否定形式

### 否定形式

> 「い」变成「く」，并在后面加「ないです」或「ありません」

- A1「く」「ないです」
- A1「く」「ありません」

### 特殊词

> 「いいです」结尾的词变成「よくないです」

或

> 「いいです」结尾的词变成「よくありません」

## 三、A1做谓语时的过去式

> 描述过去体验过的事物的性质时，在日语中必须使用过去式

### 过去式

「い」变成「かった」＋「です」

### 过去的否定式

「い」变成「くなかったです」

或

「い」变成「くありませんでした」

## 四、一类形容词+ 名

- 一类形容词可以直接修饰名称
- 形容词和名词之间不能加「の」

## 五、を→は

「を」前面的名词作话题或者对比时可替换成「は」

不能变成”～「をは」“的形式

## 六、「あまり」A1 / V（否定）

「あまり」与后面的否定形式呼应表示程度不高

> 不那么~

七、表示程度的副词①

- 「とても」「たいへん」「少し」「ちょっと」「あまり」「全然」都是表示程度的副词
- 「あまり」「全然」要与后面的否定形式呼应使用

轻重程度如下

| 日语             | 中文     |
| ---------------- | -------- |
| とても／たいへん | 很，非常 |
| 少し／ちょっと   | 一点儿   |
| あまり～ません   | 不太~    |
| 全然～ません     | 根本不~  |
