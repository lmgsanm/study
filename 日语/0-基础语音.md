##  促音「っ」

**促音 = 小さい「っ」**，表示后面的辅音需要停顿/加倍。

例如：

| 日语     | 罗马字 | 意思        |
| -------- | ------ | ----------- |
| きって   | kitte  | 邮票        |
| がっこう | gakkou | 学校        |
| ざっし   | zasshi | 杂志        |
| いっぱい | ippai  | 满满地/一杯 |
| きっぷ   | kippu  | 票          |

例如：

**きて（kite）** ≠ **きって（kitte）**

「っ」不是单独发一个音，而是让后面的辅音有一个短暂停顿。

## 长音「ー / あ・い・う・え・お」

长音就是**把元音拉长一拍**。

### 平假名

| 形式   | 例子       | 罗马字  |
| ------ | ---------- | ------- |
| あ＋あ | おばあさん | obaasan |
| い＋い | おにいさん | oniisan |
| う＋う | くうき     | kuuki   |
| え＋え | おねえさん | oneesan |
| お＋う | こうこう   | koukou  |

### 片假名

片假名里最常见的是 **「ー」**：

- コーヒー → **koohii** → 咖啡
- ケーキ → **keeki** → 蛋糕
- スーパー → **suupaa** → 超市
- タクシー → **takushii** → 出租车

## 学习顺序

如果你是**零基础开始学日语**，建议按这个顺序记：

**① 五十音**
 あ → か → さ → た → な → は → ま → や → ら → わ

**② 浊音・半浊音**
 が → ざ → だ → ば → ぱ

**③ 拗音**
 きゃ → しゃ → ちゃ → にゃ → ひゃ……

**④ 促音**
 っ

**⑤ 长音**
 おばあさん、コーヒー

**⑥ 外来语特殊音**
 ファ、ティ、ディ、チェ……

## 输入法操作

基础操作与快捷键

- **切换输入法**：使用 `Windows键 + 空格键` 切换语言，使用 `Alt + ~` (Esc下方按键) 在英文字母输入和平假名输入间切换。
- **平片假名转换**：输入罗马音后，按 `F6` 变为平假名，按 `F7` 变为全角片假名。
- **手写板功能**：右键点击任务栏输入法图标（“あ”或“A”），打开 **IME Pad**（IME板）使用手写或笔画查字。

常用罗马音输入规则

- **拨音（ん/ン）**：连续打两个 `n`（例如：`nn` -> ん）。
- **促音（小っ）**：双打后一个辅音字母（例如：`motto` -> もっと）。
- **长音（ー）**：按键盘右上方的减号键 `-`。
- **特殊假名**：`じ` 可输入 `ji` 或 `zi`，`し` 可输入 `shi` 或 `si`，`づ` 输入 `du`，`ぢ` 输入 `di`
