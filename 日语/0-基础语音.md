## 促音「っ」

**促音 = 小さい「っ」**，表示后面的辅音需要停顿/加倍。

例如：

| 日语     | 罗马字 | 意思        |
| -------- | ------ | ----------- |
| きって   | kitte  | 邮票        |
| がっこう | gakkou | 学校        |
| ざっし   | zasshi | 杂志        |
| いっぱい | ippai  | 满满地/一杯 |
| きっぷ   | kippu  | 票          |

例如：

**きて（kite）** ≠ **きって（kitte）**

「っ」不是单独发一个音，而是让后面的辅音有一个短暂停顿。

## 输入法操作

基础操作与快捷键

- **切换输入法**：使用 `Windows键 + 空格键` 切换语言，使用 `Alt + ~` (Esc下方按键) 在英文字母输入和平假名输入间切换。
- **平片假名转换**：输入罗马音后，按 `F6` 变为平假名，按 `F7` 变为全角片假名。
- **手写板功能**：右键点击任务栏输入法图标（“あ”或“A”），打开 **IME Pad**（IME板）使用手写或笔画查字。

常用罗马音输入规则

- **拨音（ん/ン）**：连续打两个 `n`（例如：`nn` -> ん）。
- **促音（小っ）**：双打后一个辅音字母（例如：`motto` -> もっと）。
- **长音（ー）**：按键盘右上方的减号键 `-`。
- **特殊假名**：`じ` 可输入 `ji` 或 `zi`，`し` 可输入 `shi` 或 `si`，`づ` 输入 `du`，`ぢ` 输入 `di`

# 日语标音法

高读类型拼音第一声，低读相当于第三声

日语单词中，一旦从高音到低降下来，就不会再有高音了

## 数字标记法

### 0调

> 第一个假名为低音之后的假名都为高音，并保持一个平的调

### 1调

> 第一个假名为高音，之后的假名都是低音

### 2调

> 第二个假名为高音，其余都为低音

### 3调

> 第二个和第三个假名为高音，其余都为低音

### 4调

> 第二个到第四个假名为高音，其余都为低音

## 常用标音方法

### ① 数字标记法

日语词典常用 **0、1、2、3……** 表示音调核的位置。

例如：

- **日本（にほん）⓪** → 平板型
- **学生（がくせい）⓪** → 平板型
- **ありがとう②** → 第二拍之后下降

数字表示的是**从哪里开始下降**，不是中文意义上的“第几声”。

### ② ○数字标记

也经常写成：

- **⓪** 平板型
- **①** 头高型
- **②** 中高型
- **③** 中高型
- **④** ……

例如：

**雨（あめ）①**
 `H ↓ L`

**飴（あめ）⓪**
 `L H H`

### ③ 高低线标记

学习日语音调时，我更推荐这种：

- **L** = 低音
- **H** = 高音
- **↓** = 音高下降

例如：

**はし（箸）**
 `H L`

**はし（橋）**
 `L H`

这样可以直接看出音高变化。

### ④ 常见的五种类型

日语东京式音调通常分成：

| 类型         | 特点                         |
| ------------ | ---------------------------- |
| **平板型 ⓪** | 第一个音低，之后保持高       |
| **头高型 ①** | 第一个音高，马上下降         |
| **中高型**   | 中间某处下降                 |
| **尾高型**   | 单词本身不下降，加助词后下降 |
| **复合型**   | 较复杂的音调模式             |

## ①②③④⑤读音

> **①②③④⑤表示“从第几个音拍之后下降”，不是中文的一声、二声、三声。**

假设一个词有 **5拍**，可以这样理解：

```
①型
高 ↓ 低 低 低 低
①    2   3   4   5
```

也就是**第1拍后下降**。

------

### 日语音调 ①②③④⑤ 示意图

| 类型    | 音高示意             | 怎么读               |
| ------- | -------------------- | -------------------- |
| **①型** | **高 ↓ 低 低 低 低** | 第一拍高，马上下降   |
| **②型** | 低 **高 ↓ 低 低 低** | 第二拍最高，然后下降 |
| **③型** | 低 高 **高 ↓ 低 低** | 第三拍后下降         |
| **④型** | 低 高 高 **高 ↓ 低** | 第四拍后下降         |
| **⑤型** | 低 高 高 高 **高 ↓** | 第五拍后下降         |

可以把它画成“楼梯”：

```
①型
高 ━┓
    ┗━━━━━━ 低


②型
低 ━┓
    ┗━ 高 ━┓
            ┗━━ 低


③型
低 ━┓
    ┗━ 高 ━━┓
             ┗━━ 低


④型
低 ━┓
    ┗━ 高 ━━━━━┓
                ┗━━ 低


⑤型
低 ━┓
    ┗━ 高 ━━━━━━━━━┓
                    ┗━ 低
```

不过，这里有一个**非常重要的细节**：

### ①型和②③④⑤型的区别

以 **5拍的词**为例：

**①型：**

> **第1拍高 → 第2拍马上变低**

```
H ↓ L L L L
```

**②型：**

> 第1拍低 → 第2拍高 → **第2拍后下降**

```
L H ↓ L L
```

**③型：**

```
L H H ↓ L
```

**④型：**

```
L H H H ↓ L
```

**⑤型：**

```
L H H H H ↓
```

------

### 还有一个特别重要的：⓪型

**⓪不是“没有音调”**。

它叫**平板型（へいばんがた）**：

```
L H H H H
```

特点是：

> 第一个拍低，从第二拍开始高，**词内部不下降**。

例如：

**学生（がくせい）⓪**

可以粗略理解成：

```
が く せ い
L  H  H  H
```

------

### 一句话记忆

你可以直接记这个：

```
⓪：  L H H H H   → 不下降

①：  H ↓ L L L   → 第1拍后下降

②：  L H ↓ L L   → 第2拍后下降

③：  L H H ↓ L   → 第3拍后下降

④：  L H H H ↓ L → 第4拍后下降

⑤：  L H H H H ↓ → 第5拍后下降
```

**数字 = 音调核（アクセント核）所在的位置，也就是下降的位置。**
