

# 语法

## 一、今 ~ 時	~分です



①	常用［今・～時・~分です］

②	「いま」可以省略

③	询问具体时间用「何時」

④　30分可以用【半】来表示

⑤	具体的时间前面还可以加「午前」「午後」

示例：　

①	今　4時です

②	今	何時ですか。	ー8時30分です

③	今	午前　八時半です

## 二、动词

> 动词是说明事物的**动作·状态·存在·变化**的词，由词干和词尾构成

动作：走る（はしる）·飛ぶ（とぶ）·歩く（あるく）……

状态：疲れる（つかれる）·憂る（うれる）……

存在：ある	いる

变化：なる

> 词尾是[う段假名]会有形态变化

### 【一类】动词

> 词尾在う段（特征不明显）

- 「あ」う

- 「ある」く

- 「あよ」ぐ

- 「はな」す

- 「う」つ

- 「し」ぬ

- 「あそ」ぶ

- 「ぬす」む

- 「おく」る

  

### 【二类】动词

> ①词尾是る
>
> ②倒数第二个假名是い段／え段

示例：

1. 起きる
2. 食べる
3. 集[あつ]める

### 【三类】动词

> ①来「く」る（只有这一个）
>
> ②する
>
> ③动作性名称 + する

示例：

1. 勉強　＋　する　＝　勉強する
2. 買い物　＋　する　＝　買い物する
3. 研究　＋　する　＝　研究する
4. 旅行　＋　する　＝　旅行する



## 动词的变形

1. ます：**是动词的敬体形式**
2. すせん
3. ました
4. ませんでした

### 【一类】动词变形

> 动词词典型「基本型」词尾
>
> 「う」→「い」段假名 + ます

1. 読む(よ)む　①　=>　読みます
2. 買(か)う　⓪　=>　買います
3. 送(おく)る　=>　送ります

### 【二类】动词变形

> 将动词词典形词尾去年「る」＋「ます」

1. 見(み)る　=>　見ます
2. 食(た)べる　=>　食べます
3. 起(お)きる　=>　起きます

### 【三类】动词变形

> ①来(く)る　=>　来(き)ます
>
> ②まる　=>　します
>
> ③动词性名称+まる　=>　动词性名称+します

1. 卒業まる　=>　卒業します
2. 勉強まる　=>　勉強します
3. お願いする　=>　お願いします

## 四种礼貌的表达形式

1. 一般现在时：～ます                        【否定形式】ません
2. 叙述过去的动作时：～ました          【否定形式】ませんでした
